## 0. 자동 점검 먼저 (사람 눈으로 세기 전에)

```bash
python3 tools/abap_check.py <파일>            # 오류 0건 필수 (CHK-001~017)
grep -n "TODO(교체)" <파일>                    # 골격 교체 지점 잔류 0건
```

아래 B·C의 기계 판별 가능 항목은 이 명령으로 이미 점검된다. 사람은 **A(업무 정확성)** 와
점검기가 보지 못하는 항목에 집중한다.

## A. 정확성 (Activation 전에 AI가 자가점검 — 점검기 대상 아님)

- [ ] DDIC 필드명이 수집값(`ddic-collect`)·`context/ddic-cache.md` 확정 행과 일치한다 (추측 필드에는 `[확인필요]` 표기)
- [ ] 조인 조건·WHERE가 스펙 §1과 일치한다
- [ ] 메시지 클래스·번호가 SE91 정의서와 일치한다 (하드코딩 `e001` 단독 사용 없음)
- [ ] `SY-SUBRC`가 모든 DB I/O·BAPI·RFC 호출 직후 체크된다

## B. 안정성·성능

- [ ] `SELECT *`·루프 내 `SELECT`·`COMMIT` 남용 없음 *(CHK-001/002/011)*

- [ ] 대량(1만건+)는 `PACKAGE SIZE`·배치잡·잡 로그 고려됨 — 사람 판단
- [ ] `AUTHORITY-CHECK` 누락 없음 (없으면 TODO 명시) *(CHK-016)*
- [ ] 조인 방향·집계 단위가 업무상 맞다 — 사람 판단
