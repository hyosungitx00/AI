# 질문 제시 공통 양식 — 번호 선택형 (타이핑 최소화)

> 이 저장소의 **모든 사용자 질문**(세션 시작 8문항, 인터뷰 I-0~I-8, Gate U·D·F·2, Verify V-1~V-4, Handover H-1)에 적용되는 공통 양식이다.
> 목적: 사용자가 **문장을 쓰지 않고 번호만 눌러서** 답하게 한다.

## 0. 왜 두 가지 모드인가

선택지를 클릭하는 질문 카드는 **AI 도구(클라이언트)가 제공할 때만** 쓸 수 있다.
저장소 규칙이나 프롬프트로는 클릭 UI를 만들어 낼 수 없다. 따라서 모드를 나눈다.

| 모드 | 조건 | 방식 | 사용자 조작 |
|---|---|---|---|
| **A. 클릭 카드** | 이 세션에 선택형 질문 도구(`AskQuestion` 등)가 붙어 있을 때 | 그 도구로 질문 | 선택지 클릭 |
| **B. 번호 선택형** | 도구가 없을 때 (웹/클라우드 에이전트 등) | 아래 §1 양식의 텍스트 | 번호 한두 글자 입력 |

- AI는 턴을 시작할 때 자신에게 선택형 질문 도구가 있는지 확인하고, **있으면 무조건 모드 A**를 쓴다.
- 도구가 없으면 **모드 B로 묻고, 첫 질문 위에 한 줄로 사유를 밝힌다**:
  `"이 세션에는 클릭형 질문 도구가 없어 번호 선택형으로 묻습니다. 번호만 입력해 주세요."`
- 모드 B에서도 **자유 서술 요구는 금지**다. 문장으로 답하게 하지 말고 §2 규칙으로 선택지를 만들어 낸다.

## 1. 모드 B 질문 양식 (고정)

```text
이 세션에는 클릭형 질문 도구가 없어 번호 선택형으로 묻습니다. 번호만 입력해 주세요.

Q1. SAP 릴리스  (1개 선택)
  1) ECC 6.0 · NW 7.31 이하 (보수적)
  2) NW 7.40
  3) ★ NW 7.50 · S/4HANA (모던 허용)
  4) 모름 → ECC 호환으로 진행

Q2. 주력 프로그램 유형  (여러 개 선택 가능)
  1) ★ ALV 리포트 (SE38)
  2) ★ Function Module (SE37)
  3) Module Pool
  4) Enhancement (BAdI·Exit)
  5) 그 외 → 다음 문항에서 지정

답변: 문항 순서대로 번호만 (예: `3 12`)  ·  전부 기본값 = `0`  ·  모름 = `?`
```

양식 규칙:

1. 문항 머리는 `Q번호.` + **짧은 제목** + `(1개 선택)` 또는 `(여러 개 선택 가능)`.
2. 선택지는 `  1)` 들여쓰기 번호. **한 문항당 최대 5개**.
3. 기본값에는 `★`를 붙인다. 기본값이 없는 문항이면 붙이지 않는다.
4. 마지막 선택지는 언제나 빠져나갈 길을 둔다 — `모름 → AI가 제안` 또는 `해당 없음` 또는 `직접 입력`.
5. 문항 묶음 맨 아래에 **답변 안내 한 줄**을 그대로 붙인다.
6. 한 턴에 묻는 문항 수는 기존 규칙을 따른다 (세션 시작 4문항, 인터뷰 3문항).

## 2. 서술형 질문을 선택형으로 바꾸는 규칙

인터뷰에는 원래 문장 답이 필요한 문항이 있다 (`I-1 목적`, `I-4 출력 항목`, `I-8 테스트값` 등).
이런 문항도 **그냥 물어보지 않는다.** AI가 먼저 후보를 만들어 선택지로 제시한다.

1. 지금까지의 답변·`context/system-context.filled.md`·`examples/filled/`를 근거로 **그럴듯한 후보 3개**를 만든다.
2. 후보를 `1) 2) 3)`으로 제시하고, `4) 직접 입력`, `5) 모름 → AI가 정함`을 덧붙인다.
3. 사용자가 `4`를 고른 뒤에만 문장 입력을 받는다.
4. 후보는 **추정**이므로 `[추정]`으로 표시하고, Gate U 이해도 확인서에 모아 다시 점검받는다.

예 (`I-1 목적`):

```text
Q4. 이 프로그램의 목적  (1개 선택)  [추정 후보]
  1) 영업조직·기간별 판매실적을 SE38 화면에서 조회
  2) 구매요청(PR) 현황을 담당자별로 조회
  3) 특정 문서의 상태 변경 이력을 추적
  4) 직접 입력 (한 줄로 적어 주세요)
  5) 모름 → AI가 정함
```

한 턴에 `직접 입력`이 필요할 수 있는 문항은 **최대 1개**만 둔다.

## 3. 답변 표기법 (사용자용)

| 입력 | 뜻 |
|---|---|
| `3` | 그 문항 3번 선택 |
| `3 12 1` | 문항 순서대로 Q1=3, Q2=1·2, Q3=1 |
| `1,2` | 복수 선택 (`12`와 동일) |
| `0` | 이 묶음 **전부 기본값(★)**으로 진행 |
| `?` | 그 문항 모름 → AI가 `[추정]`으로 메움 |
| `Q3=2` | 앞서 답한 문항만 고쳐 지정 |
| (빈칸·`ok`) | `0`과 동일 — 전부 기본값 |

## 4. AI 처리 규칙

1. 답변을 받으면 **선택 결과를 한 줄로 되읽어 확인**한다.
   예: `확인 — 릴리스 750/S4, 주력 ALV+FM, ALV 건별 선택, 엄격 게이트.`
2. 번호가 범위를 벗어나거나 문항 수와 개수가 맞지 않으면, **전체를 다시 묻지 말고** 어긋난 문항 하나만 다시 제시한다.
3. `0`·빈칸이면 기본값으로 확정하고 되묻지 않는다.
4. `?`가 온 문항은 `[추정]`으로 메우고 진행하되, Gate U에 모아 다시 점검받는다.
5. 기본값이 없는 문항(예: 테스트값)에 `0`이 오면 그 문항만 §2 후보 제시로 다시 묻는다.
