# 세션 답변지 — 질문 대신 한 번에 채워 붙여넣는 4종 블록 (유일한 질문 UI)

> AI는 사용자에게 질문을 한 턴씩 던지지 않는다. 아래 블록을 그대로 제시하고,
> 사용자는 아는 칸만 채워 **통째로 붙여넣기**하면 된다.
> 빈칸·`[모름]`은 AI가 제안·가정(`[추정]` 표시)으로 메우고 다음 게이트에서 확정받는다. 되묻지 않는다.
> `기본값으로 진행` 한 줄 답변은 전 항목 기본값(★)으로 처리한다.
> 표·체크박스 형식은 지우지 말고 값을 채운다 (AI 파싱용).

## 답변지 S — 세션 설정 (새 대화 첫 턴, 8문항 1블록)

```text
[세션 설정 답변지 — 빈칸=★기본값, [x]로 표시해 통째로 붙여넣으세요]
1. SAP 릴리스: [ ]a ECC 6.0 이하(보수적) [ ]b NW 7.40 [x]c ★NW 7.50·S/4HANA(모던 허용) [ ]d 모름-ECC호환
2. 주력 유형(복수): [x]a ★ALV 리포트 [x]b ★Function Module [ ]c Module Pool [ ]d Enhancement [ ]e Interface [ ]f Batch [ ]g Forms
3. ALV 방식: [x]a ★건별 유연 선택 [ ]b CL_SALV_TABLE 고정 [ ]c REUSE 고정 [ ]d CL_GUI_ALV_GRID 고정
4. 워크플로우: [x]a ★엄격 게이트(빈칸 시 코드 금지·스펙 OK 후 코드) [ ]b 빠른 진행(스펙+코드 한 번에) [ ]c 둘 다 지원
5. 추가 유형: [x]a ★없음-ALV+FM만 [ ]b Enhancement 포함 [ ]c Interface·Batch 포함 [ ]d Module Pool·Forms 포함
6. 네이밍·패키지: [x]a ★AI 제안 규칙(Z+모듈약어) [ ]b 사내 고정 규칙 있음(아래에 기입: ____)
7. 주석·한글: [x]a ★한국어+영문 병기 [ ]b 영문만(GUI 한글 불가) [ ]c 한국어 위주
8. AI 도구: [x]a ★Cursor(Rules 등록) [ ]b ChatGPT·Claude [ ]c 둘 다·사내 LLM [ ]d 매번 복붙(등록 안 함)
```

제시 후 AI 동작: 답변지를 파싱해 `context/system-context.filled.md` 초안 + 적용값 한 줄(릴리스·주력 유형·게이트·네이밍·주석·도구)을 보여주고, 바로 답변지 I를 제시한다.

## 답변지 I — 신규 프로그램 인터뷰 (접수 전용, I-0~I-8 1블록)

```text
[인터뷰 답변지 — 아는 만큼만 적고 모르면 [모름], 빈칸은 AI 제안으로 진행합니다. 통째로 붙여넣으세요]
I-0 접수: 신규/변경=____(변경이면 기존명+변경점 한 줄) / 데모=[ ]있음(위치: ____) [ ]없음-AI 생성 / 희망 유형=[ ]01 ALV [ ]02 화면 [ ]03 함수 [ ]04 강화 [ ]05 연동 [ ]06 배치 [ ]07 서식 [ ]모름
I-1 요약: 목적 한 줄=____ / 사용자·빈도=____ / 대체 프로그램=____
I-2 기능: ①____ ②____ ③____
I-3 입력: 입력 항목(필수·범위 표시)=____ / 기본값=____ / 입력 검증=____
I-4 출력: 출력 형태=[ ]조회 ALV [ ]입력 후 저장 [ ]외부 전송·파일 [ ]출력 서식 / 출력 항목=____ / 결과 동작(클릭 이동 등)=____
I-5 데모: (데모 있음이면 화면별 설명 — 화면명·입력칸·버튼·동작=____) (없으면 비워 두기 — AI가 목업 생성)
I-6 데이터: 후보 테이블·필드=____ / 조인·조건=____ / 기존 함수·BAPI=____
I-7 권한·예외: 권한 오브젝트=____ / 0건·실패 시=____ / 개인정보=[ ]미포함 [ ]포함-마스킹 [ ]모름
I-8 테스트값: T1 정상=____ / T2 0건=____ / T3 권한·검증=____
```

제시 후 AI 동작: 답변지를 모아 Gate U 이해도 확인서를 제시한다. 빈칸·`[모름]`은 `[추정]` 제안으로 메우고 확인서에 모아 점검받는다. 다시 질문하지 않는다.

## 답변지 V — 활성화·실행·오류 회수 (코드 제공 후 1블록)

```text
[V 답변지 — 해당 항목만 적고 통째로 붙여넣으세요]
V-1 활성화: Syntax Check(Ctrl+F2)=[ ]에러 0건 [ ]에러 있음(행번호+메시지 전문: ____) / Extended Check=[ ]Error 0건 [ ]있음(내용: ____)
V-2 실행: T1 정상=[ ]정상 ALV 표시 [ ]덤프·오류(증상: ____) / T2 0건=[ ]규정 메시지 표시 [ ]다르게 동작(내용: ____) / T3 권한·검증=[ ]규정 메시지 [ ]다르게 동작(내용: ____) [ ]해당 없음
V-3 오류(있을 때만): ST22 덤프명 또는 메시지 전문=____ / 케이스(T1/T2/T3)·행번호=____ / SY-SUBRC=____
V-4 확정: [ ]Handover로 진행(OK) [ ]수정(내용: ____)
```

회수 후 AI 동작: `practice/error-patterns.md`를 먼저 대조한다. 기존 패턴이면 그 ID 처방으로, 신규면 새 ID로 패턴 추가 후 수정본을 제공한다. 오류 2건 이상이면 세션 폴더 `errors.md` 양식(V-3b)으로 정리해 위에서부터 1건씩 순차 수정한다.

## 답변지 H — 운영 이관 (Verify 확정 후 1블록)

```text
[H 답변지 — 통째로 붙여넣으세요]
H-1 이관: T-code=[ ]필요(희망 코드: ____) [ ]불필요(SE38 실행) / SU53 TRACE=[ ]이상 없음 [ ]오브젝트 추가 필요(내용: ____) / 이송 희망일=____ / 배치잡=[ ]불필요 [ ]필요(주기: ____)
완료 확인: [ ]완료 [ ]수정(내용: ____)
```

제시 후 AI 동작: Handover 묶음(SE93 안내·권한 목록·TR 초안·운영 주의사항)을 제공한다. `완료` 답을 받아야 세션 종료.
