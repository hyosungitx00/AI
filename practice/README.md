# practice/ — 오류·교훈 패턴 축적 (세션 공유 지식)

> 프로그램 실행·활성화 오류와 설계 교훈 중 "다음 세션에서도 같은 답이 나올 것"을 패턴으로 쌓는다.
> AI는 **Gate 3 코드 생성 전(`code-review-checklist`와 함께) 이 파일을 반드시 확인**하고,
> 해당 패턴을 코드에 선반영한다. V-3에서 회수된 신규 오류는 아래 승격 규칙으로 추가한다.

## 사용 규칙

1. Gate 3 전 확인: 코드 작성 전 `error-patterns.md` 전 항목을 대조하고, 해당 항목을 코드·주석에 반영한다.
2. V-3 승격: 오류 회수 시 기존 패턴 ID가 있으면 그 ID로 답하고, 없으면 새 ID(ERR-nnn / MSG-nnn / PROC-nnn)로 추가한다.
3. 한 패턴은 증상·원인·처방·사전방지 4행으로만 적는다 (장문 금지).
4. 기계 점검 승격: 신규 패턴이 코드 형태로 판별 가능하면 `tools/abap_check.py`의 `CHK-nnn` 규칙으로도 추가하고
   `error-patterns.md`의 `자동 점검` 열에 연결한다 (절차는 `tools/README.md`). 같은 오류가 다음 세션에서
   사람 대조에 의존하지 않도록 만드는 것이 목적이다.
5. 골격 선반영: 패턴이 모든 신규 프로그램에 적용되는 것이면 `templates/abap/` 골격에도 반영한다.

## 패턴 ID 규칙

- `ERR-nnn`: 덤프·Syntax·실행 오류 (예: ERR-001)
- `MSG-nnn`: 메시지·권한 처리 관행 (예: MSG-001)
- `PROC-nnn`: 데모·설계·진행 관행 (예: PROC-001)
