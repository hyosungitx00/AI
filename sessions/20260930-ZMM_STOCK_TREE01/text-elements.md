# 텍스트 요소 정의서 — ZMM_STOCK_TREE01

> 작성 2026-10-01 / 세션 `20260930-ZMM_STOCK_TREE01`
> 대상: SE38 → 프로그램 `ZMM_STOCK_TREE01` → **이동(Goto) → 텍스트 요소(Text elements)**
> 기준: `practice/screen-text-detail.md` §B — 텍스트 요소는 코드로 복붙할 수 없으므로 입력값을 전수 표로 정의한다.

텍스트 요소는 **소스 코드가 아니다.** 프로그램을 붙여넣고 활성화해도 라벨은 채워지지 않는다. 별도 유지보수 화면에서 손으로 넣고 저장해야 한다. 넣지 않으면 선택화면에 `S_BUKRS` 같은 **필드명이 그대로** 라벨 자리에 보인다(동작은 정상, 사용성만 나쁨).

## §1 텍스트 요소 4종 중 이 프로그램이 쓰는 것

| 종류 | 이 프로그램 | 이유 |
|---|---|---|
| **선택 텍스트 (Selection texts)** | **사용 — 10건** | 선택화면 필드 10개의 라벨. §3 |
| **프로그램 제목 (Title)** | **사용 — 1건** | SE38 속성의 짧은 설명. §4 |
| 텍스트 심볼 (Text symbols, `TEXT-xxx`) | **사용 안 함 — 0건** | §5 |
| 리스트 머리글 (List headings) | **사용 안 함 — 0건** | §6 |

GUI 타이틀 `TIT0100` 과 GUI 상태 `STAT0100` 은 텍스트 요소가 **아니다.** SE41 의 별개 오브젝트이며 `screen-0100.md` §3·§4 에 정의했다. 혼동하기 쉬운 지점이다.

## §2 선택 텍스트 유지보수 경로

```text
SE38 → 프로그램 ZMM_STOCK_TREE01 입력
     → 이동(Goto) → 텍스트 요소(Text elements) → 선택 텍스트(Selection texts)
     → §3 표대로 입력 → 저장(Ctrl+S) → 활성화
```

- 칼럼 구성은 릴리스마다 조금 다르지만 공통으로 **① 이름(Name) ② 텍스트(Text) ③ 사전 참조(Dictionary ref.) 체크박스** 3칼럼이다.
- 이름 칼럼은 프로그램에서 읽어와 **이미 10행이 채워진 상태**로 열린다. 행을 추가·삭제하지 않는다. 비어 있으면 프로그램이 활성화되지 않은 것이다.
- 텍스트 입력칸은 30자다. 한글은 선택화면 라벨 폭을 많이 차지하므로 **12자 이내**로 쓰는 것이 보기 좋다. §3 의 값은 모두 12자 이내다.
- 텍스트 요소는 **언어별**로 저장된다. 한글 라벨을 보려면 **유지보수 언어와 로그온 언어가 같아야** 한다. 한국어로 로그온해서 입력하면 그대로 맞는다.

### 2.1 사전 참조(Dictionary ref.) 를 쓸지 여부

`S_BUKRS` ~ `S_MATKL` 6건은 DDIC 필드를 참조(`SELECT-OPTIONS ... FOR t001-bukrs`)하므로 사전 참조 체크박스를 켜면 텍스트를 직접 쓰지 않아도 된다. 다만 **그때 보이는 라벨은 데이터 요소의 번역값**이다(`BUKRS` → Company Code / 회사 코드 …). 시스템에 한국어 번역이 없으면 영문이 그대로 뜬다.

| 방식 | 장점 | 단점 | 이 세션 선택 |
|---|---|---|---|
| ① 사전 참조 체크 | 6건을 한 번에 처리, 표준 용어와 일치 | 라벨이 시스템 번역에 의존 — 결과가 확정적이지 않다. 체크하면 텍스트 칼럼이 입력 불가로 바뀐다 | 쓰지 않음 |
| ② **직접 입력** | 10건 모두 §3 표대로 **확정적으로** 나온다. 용어를 현업 표현으로 맞출 수 있다 | 10행을 손으로 입력 | **채택** |

10행뿐이고 복붙 계약상 "표에 적은 대로 보인다"가 보장되는 쪽이 낫다. **사전 참조 체크박스는 10건 전부 끈 상태로 두고 §3 의 텍스트를 직접 입력한다.**
이미 사전 참조로 채워 놓았다면 그대로 둬도 기능에는 문제가 없다. 라벨 문구만 표준 용어로 달라진다.

## §3 선택 텍스트 — 입력값 전수 (10건)

`순서` 는 선택화면에 나타나는 위, 아래 순서다. 유지보수 화면의 행 순서와 같다.

### 3.1 블록 1 — 조회 조건 (SELECT-OPTIONS 6건)

| 순서 | 이름 Name | **텍스트 Text (입력값)** | 길이 | 사전 참조 | DDIC 참조 | 필수 |
|---|---|---|---|---|---|---|
| 1 | `S_BUKRS` | `회사코드` | 4 | 끔 | `T001-BUKRS` | ★ 필수 — 비면 실행 차단 |
| 2 | `S_WERKS` | `플랜트` | 3 | 끔 | `T001W-WERKS` | 선택 |
| 3 | `S_LGORT` | `저장위치` | 4 | 끔 | `T001L-LGORT` | 선택 |
| 4 | `S_MATNR` | `자재번호` | 4 | 끔 | `MARA-MATNR` | 선택 |
| 5 | `S_MTART` | `자재유형` | 4 | 끔 | `MARA-MTART` | 선택 |
| 6 | `S_MATKL` | `자재그룹` | 4 | 끔 | `MARA-MATKL` | 선택 |

6건 모두 `SELECT-OPTIONS` 이므로 선택화면에 **단일값·범위·다중선택 버튼**이 함께 나온다. 라벨은 단일값 칸 왼쪽에 1번만 표시된다.

### 3.2 블록 2 — 표시 옵션 (PARAMETERS 4건)

| 순서 | 이름 Name | **텍스트 Text (입력값)** | 길이 | 사전 참조 | 유형 | 기본값 |
|---|---|---|---|---|---|---|
| 7 | `P_HIDE0` | `재고 0 자재 숨기기` | 10 | **불가** | 체크박스 | `X` (켜짐) |
| 8 | `P_SPEC` | `특별재고 포함` | 7 | **불가** | 체크박스 | `X` (켜짐) |
| 9 | `P_VAL` | `평가액 표시` | 6 | **불가** | 체크박스 | 공란 (꺼짐) |
| 10 | `P_MAXROW` | `최대 표시 자재 행` | 9 | **불가** | 입력 필드 `TYPE i` | `10000` |

4건은 DDIC 를 참조하지 않는다(`AS CHECKBOX`, `TYPE i`). **사전 참조가 원천적으로 불가능하므로 직접 입력이 유일한 방법이다.** 여기를 비워두면 선택화면에 `P_HIDE0` 처럼 필드명이 그대로 보인다.

- 체크박스 3건은 라벨이 체크박스 **오른쪽**에 붙는다.
- `P_MAXROW` 는 이름이 8자로, ABAP 선택화면 필드명 상한(8자)에 딱 맞다. 더 긴 이름으로 바꾸면 구문 오류가 난다.

### 3.3 라벨 의미 (현업 설명용)

| 이름 | 라벨 | 동작 |
|---|---|---|
| `P_HIDE0` | 재고 0 자재 숨기기 | 켜면 가용·품질검사·보류 수량이 모두 0 인 자재 노드를 트리에서 제외 |
| `P_SPEC` | 특별재고 포함 | 켜면 MSKA·MSPR·MSKU·MKOL·MSLB 특별재고를 `특별재고` 노드로 추가. 끄면 MARD 저장위치 재고만 |
| `P_VAL` | 평가액 표시 | 켜면 MBEW 기준 평가액(`SALK3` 비례배분) 칼럼을 채움. 끄면 공란 |
| `P_MAXROW` | 최대 표시 자재 행 | 자재 노드 수가 이 값을 넘으면 트리를 만들지 않고 안내 메시지 후 중단. 노드는 1건씩 생성되므로 과다 건수에서 화면 생성이 느려지는 것을 막는 안전장치 |

## §4 프로그램 제목 (Title)

| 항목 | 값 |
|---|---|
| 입력 위치 | SE38 → 프로그램 속성(Attributes) → **짧은 설명(Short description)** |
| **입력값** | `법인/플랜트별 재고 현황 트리 조회` |
| 길이 | 16자 (상한 70자) |
| 보이는 곳 | SE38 초기화면, SE80 오브젝트 목록, 선택화면 상단 제목, SE93 T-code 생성 시 기본값 |

## §5 텍스트 심볼 (`TEXT-xxx`) — 0건, 의도적으로 쓰지 않음

이 프로그램에는 `TEXT-001` 같은 참조가 **하나도 없다.** 선택화면 블록 제목 2개도 텍스트 심볼이 아니다.

| 보이는 문구 | 구현 | 근거 |
|---|---|---|
| 블록 1 제목 `조회 조건 / Selection criteria` | `INITIALIZATION` 에서 `gv_tit1` 에 대입 | ERR-007 |
| 블록 2 제목 `표시 옵션 / Display options` | `INITIALIZATION` 에서 `gv_tit2` 에 대입 | ERR-007 |
| 트리 칼럼 머리글·노드 문구·메시지 | 소스 내 문자열 리터럴 | 복붙 계약 |

```abap
SELECTION-SCREEN BEGIN OF BLOCK b1 WITH FRAME TITLE gv_tit1.
...
INITIALIZATION.
  gv_tit1 = '조회 조건 / Selection criteria'.
  gv_tit2 = '표시 옵션 / Display options'.
```

`WITH FRAME TITLE gv_tit1` 은 `gv_tit1` 을 **컴파일러가 암시적으로 선언**한다. `DATA gv_tit1 ...` 을 같이 쓰면 `"GV_TIT1" was already declared` 구문 오류가 난다(실측, `spec.md` §11.3). 이름은 8자 이내여야 한다.

**이유:** 텍스트 심볼을 쓰면 복붙만으로는 제목이 빈칸이 되고 유지보수 화면을 한 번 더 들러야 한다. 변수 대입으로 바꾸면 소스 안에서 끝난다. 번역이 필요해지면 그때 텍스트 심볼로 바꾸면 된다.

## §6 리스트 머리글 (List headings) — 0건

이 프로그램은 `WRITE` 로 리스트를 출력하지 않는다. 결과는 Dynpro 화면 0100 의 ALV 트리로 표시한다. 리스트 머리글은 입력할 것이 없다.
트리 칼럼 머리글은 `f_build_fieldcat` 의 필드카탈로그 `scrtext_l`·`coltext` 에서, 계층 칼럼 머리글은 `treev_hhdr-heading` 에서 온다. 둘 다 소스 안에 있다.

## §8 오류 대응표

| 증상 | 원인 | 조치 |
|---|---|---|
| 선택 텍스트 화면에 행이 없다 | 프로그램 미활성화 | 프로그램 활성화 후 다시 들어간다 |
| 입력했는데 선택화면이 그대로 필드명 | 저장 안 함 | 유지보수 화면에서 Ctrl+S |
| 저장했는데 영문·독문 라벨이 보인다 | 사전 참조 체크가 켜져 있다 | 체크 끄고 §3 텍스트 입력 후 저장 |
| 저장했는데 라벨이 비었다 | 유지보수 언어 ≠ 로그온 언어 | 로그온 언어로 다시 입력. 프로그램 원본 언어 확인 |
| `P_HIDE0` 행이 유지보수 화면에 없다 | 소스에서 해당 `PARAMETERS` 가 빠졌거나 이름이 다르다 | 소스의 선택화면 블록을 §3 과 대조 |
| 한글 라벨이 중간에 잘린다 | 선택화면 라벨 폭 한계 | 텍스트를 짧게 줄인다 (§3 값은 모두 12자 이내로 안전) |
| 블록 제목이 비어 있다 | 텍스트 요소 문제가 아니다 | `INITIALIZATION` 의 `gv_tit1`·`gv_tit2` 대입 2줄이 소스에 있는지 확인 |
| 창(윈도우) 제목이 비어 있다 | 텍스트 요소 문제가 아니다 | SE41 GUI 타이틀 `TIT0100` 미생성 — `screen-0100.md` §4 |

## §9 의도적으로 넣지 않은 것

| 항목 | 이유 |
|---|---|
| 다국어 번역 (SE63) | 사용자·사용 빈도 미확정(`00-intake.filled.md` I-5). 한국어 1개 언어로 충분. 필요해지면 SE63 → 번역 → 짧은 텍스트 → 프로그램 텍스트 |
| 텍스트 심볼 전환 | §5 — 복붙 계약 유지가 우선 |
| 선택화면 필드 도움말 문구(모달 F1 도움말) | DDIC 데이터 요소의 표준 문서가 F1 에 그대로 나온다. 커스텀 문서(SE61) 불필요 |
| 변형(Variant) 저장 | Handover 단계에서 사용자가 상용 조건으로 직접 저장하는 것이 맞다 |
