## §9 Gate U — 이해도 확인서 (인터뷰 I-0 ~ I-8 종합)

### 1. 목적

법인(회사코드)과 플랜트를 기준으로 재고 현황을 트리 형태로 조회하는 신규 SE38 ALV 리포트를 만든다. `MMBE`(계층형 재고 개요)와 `MB52`(플랜트 재고 목록)의 조회 성격을 한 화면에 합치는 것이 목표이며, 두 표준 트랜잭션을 대체하는 것이 아니라 참고한다.

### 2. 사용자·빈도

`[추정]` 구매·자재팀 실무자 소수, 수시 조회. (I-1 답변 `모름`)

### 3. 핵심 기능 (6건)

1. 법인 → 플랜트 → 재고 구분 → 저장위치·특별재고 유형 → 자재 순 5단 트리 전개
2. 노드별 수량 소계 — 단위가 모두 같은 노드만 수량 합산, 2종 이상이면 수량 공란 + "혼재" + 평가액만 합산 (A안)
3. 재고 유형 구분 표시 — 가용(비제한사용) / 품질검사 / 보류(제한사용)
4. 자재 노드 더블클릭 → `MM03` 자재 마스터 조회
5. 재고 평가액 표시 (선택화면 옵션으로 켤 때만)
6. 재고 0 자재 숨기기 (선택화면 옵션, 기본 켜짐)

- 제외: 엑셀 다운로드(ALV 툴바 기본 내보내기로 충족), 배치별 전개

### 4. 입력 (S1 선택화면)

- 필수: 회사코드(범위). 기본값은 사용자 개인설정(SU3) 파라미터 `BUK`
- 선택: 플랜트 · 저장위치 · 자재번호 · 자재유형 · 자재그룹 (모두 범위)
- 옵션: 재고 0 숨기기(기본 켜짐) · 특별재고 포함(기본 켜짐) · 금액 표시(기본 꺼짐)
- 검증: 회사코드 미입력 시 실행 차단 (조건 없는 전사 조회 방지)

### 5. 출력 (S2 결과화면)

- 트리 계층 5단, 각 단에 코드와 명칭 병기
- 열: 가용 / 품질검사 / 보류 / 합계 / 단위 / 평가액 · 통화(옵션) / 참조 / 자재유형 / 자재그룹
- 특별재고 구간의 최하위 노드는 자재 + 참조 조합 1건 = 1행
- 특별재고 범위: 판매오더 재고 · 프로젝트 재고 · 고객 위탁재고 · 공급업체 위탁재고 (I-6 "가능한 전부")

### 6. 예외 처리

- 0건 → `S` "조회 조건에 해당하는 재고가 없습니다" 후 선택화면 유지
- 회사코드 미입력 → `E` + 커서 이동
- 권한 없음 → `E` "해당 회사코드/플랜트 조회 권한이 없습니다" (오브젝트명은 SU53으로 확정)
