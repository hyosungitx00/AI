## 3. V-2 실행 — 2단계로 갈린 증상

### 3.1 1차 — "아무 화면도 나오지 않습니다"

`S_BUKRS = H322` 로 실행했으나 화면이 열리지 않았다. 원인이 **데이터 0건**인지 **컨트롤 미표시**인지 구분할 수 없는 상태였다.

처방: 0건 분기를 `TYPE 'S'` + `RETURN` 에서 **`TYPE 'I'` 모달**로 바꾸고, 단계별 건수 요약을 출력하도록 수정했다 (PROC-003).

### 3.2 2차 — 요약은 보이고 트리만 안 보임

수정본 실행 결과 사용자가 회신한 내용은 아래와 같다.

```text
조회 요약 / Summary
  플랜트 / Plants : 4
  재고 행 / Stock rows : 689,319
  표시 행 / Tree leaves : 7,339
```

이로써 **데이터 조회 로직은 정상이고 렌더링만 실패**했음이 확정됐다. 요약이 출력됐다는 것은 `START-OF-SELECTION` 이 끝까지 돌았다는 뜻이다.

원인: `CL_GUI_DOCKING_CONTAINER` 로 리포트 기본 목록 위에 컨트롤을 띄우는 방식이 동작하지 않았다. `frontend_update` 까지 호출하고 `repid`·`dynnr` 전달/미전달 양쪽을 모두 시도해도 동일했다 (PROC-004).

처방: **Dynpro 화면 0100 + `CL_GUI_CUSTOM_CONTAINER`** 구조로 전환했다. SAP 표준 데모 `BCALV_TREE_*` 와 같은 구조다. 이에 따라 SE51 화면 1개, SE41 GUI 상태 `STAT0100`, SE41 GUI 타이틀 `TIT0100` 이 수작업 산출물로 추가됐고, 정의서는 `screen-0100.md` · `text-elements.md` 로 제공했다 (PROC-005, PROC-006).

### 3.3 실측 수치가 설계에 미친 영향

재고 689,319 행이 표시 7,339 행으로 줄어든다는 실측값으로 상한 설계를 확정했다.
집계·소계가 있는 트리는 상한 초과 시 **자르면 소계가 왜곡**되므로, 자르지 않고 막고 조건을 좁히도록 안내한다 (PROC-007).
기본 상한 `P_MAXROW = 10000` 은 실측 7,339 행을 수용하면서 여유를 두는 값으로 정했다.

## 4. V-4 — 미검증 항목 (사용자 지시로 조기 종결)

2026-10-02 사용자 지시("완료 상태로 마무리")로 Gate 4 를 조기 종결했다.
