### 계층 규칙 (5단)

| 단 | 노드 | 비고 |
|---|---|---|
| 1 | 회사코드 + 회사명 | |
| 2 | 플랜트 + 플랜트명 | |
| 3 | 재고 구분 — `저장위치 재고` / `특별재고` | I-6 A안으로 신설. 두 재고가 같은 레벨에 섞이지 않는다 |
| 4 | 저장위치 + 명칭 (저장위치 재고 하위) / 특별재고 유형 (특별재고 하위) | |
| 5 | 자재 + 자재내역 | 특별재고 구간은 **자재 + 참조 조합 1건 = 1행** (같은 자재가 수주 2건이면 2행) |

- 특별재고의 참조 정보(판매문서·WBS·고객·공급업체)는 트리 텍스트가 아니라 별도 `참조` 열에 표시한다.
- 공급업체 보유 사급 재고처럼 우리 저장위치가 없는 유형은 4단(특별재고 유형) 바로 아래에 자재가 붙는다.

### 상위 노드 수량 소계 — A·B·C안 비교

이미지: `demo-s2-subtotal.png`

| 안 | 방식 | 장점 | 단점 |
|---|---|---|---|
| A (권장) | 단위 혼재 노드는 수량 비우고(`—`, 단위 "혼재") 금액만 합산. 단위 동일 노드는 수량 소계 표시 | 틀린 숫자를 보여주지 않음 | 플랜트·법인 단 수량 칸이 비어 보임 |
| B | 항상 합산, 단위 혼재 노드의 단위 열에 `*` | 모든 칸이 채워짐 | KG+EA 합산으로 의미 없는 값, 오해 위험 |
| C | 기준 단위(KG)로 환산해 합산 | 합산값이 물리적으로 정확 | 단위 환산 조회 추가로 느려짐, 환산계수 없는 자재는 소계 제외 |

- 결정 상태: **A안 확정** (사용자 선택 "수량 소계 A", 2026-09-30). S2 목업이 그대로 A안이다.
  - 구현 규칙: 노드 하위 자재의 기본단위가 모두 동일하면 수량 소계를 표시하고 그 단위를 찍는다. 단위가 2종 이상이면 수량 4열을 공란으로 두고 단위 열에 "혼재"를 표시하며, 금액(평가액)만 합산한다.
  - B안·C안은 채택하지 않음 (B: 단위 혼재 합산값이 부정확, C: 단위 환산 조회 부담·환산계수 누락 자재 이슈).
