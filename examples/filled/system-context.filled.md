# 작성본 예시 — 시스템 컨텍스트 (복붙용)

> `context/system-context.template.md`의 작성본 예시이다. 이 값을 그대로 AI 대화 맨 앞에 붙여넣는다.
> 실제 프로젝트에서는 `[...]` 값을 현장 시스템 값으로 교체한다.

```markdown
## §0 시스템 정보
- 시스템 종류: [x] S/4HANA OP 2022 / [ ] ECC 6.0 / [ ] 기타
- SAP_BASIS 릴리스 (System → Status): [750]
- ABAP 문법 상한: [x] 7.50+/S4 모던 허용 [ ] 7.40 [ ] ECC 6.0 호환
- ALV 선호 방식: [x] 건별 유연 선택(기본값) [ ] CL_SALV_TABLE 고정 [ ] REUSE 고정 [ ] CL_GUI_ALV_GRID 고정
- 클라이언트: 개발 100 / 검증 200 / 운영 300
- 로그온 언어: [x] KO [ ] EN / SE38 한글 주석 입력: [x] 가능(한+영 병기) [ ] 불가
- 패키지(개발클래스): [ZSD01] ($TMP 사용 금지)
- 네이밍 prefix: [AI 제안 규칙 — ZSD, 함수그룹 ZFGSD01] / 요청번호(TR) 규칙: [개발자별 생성, 이송 순서 별도 정리]
- 메시지 클래스 규칙: [ZSD_MSG 고정 사용, 신규면 SE91 생성]
- 권한 TRACE 가능 여부(SU53/ST01): [x] 가능 [ ] 불가

## §0-2 코딩 취향
- 주석 언어: [x] 한국어+영문 병기 [ ] 영문만
- SELECT 방식: [x] 모던(호스트변수 @) 허용 [ ] 보수적(지정 건만)
- 예외 처리: [x] 메시지 클래스 사용 [ ] DISPLAY LIKE 임시 허용
- 테스트 데이터 제공 방식: [x] 코드값만 제공 [ ] 마스킹 샘플 제공
```
