# 작성본 예시 — 00-intake 접수 커버 (복붙용)

> `requirements/00-intake.md`의 작성본 예시이다. 데모 없는 텍스트 접수 케이스이며,
> 이어지는 `08-demo.filled.md`(경로B AI 생성) → `09-fieldmap.filled.md`와 1세트이다.

```markdown
## §0 접수 정보
- 세션 유형: [x] 신규 프로그램 [ ] 기존 프로그램 변경
- 요구사항 형식: [x] 채팅 텍스트 붙여넣기 [ ] 파일 첨부
- 첨부 파일명: [없음-텍스트]
- 화면 데모 포함 여부: [ ] 있음 [x] 없음(AI가 생성 → Gate D에서 확인)
- 희망 프로그램 유형: [x] 모름(AI 판단에 맡김)

## §2 요구사항 본문 (A 텍스트 붙여넣기)

[요구사항 텍스트]
영업관리팀 5명이 매일 09시에 영업조직별 일별 판매실적을 SAP에서 바로 조회하고 싶다.
엑셀 정리 없이 판매문서·고객·순매출을 보고, 조건에 맞는 데이터가 없으면 메시지가 나와야 한다.
판매조직은 필수로 입력하고 생성일은 범위로 입력한다. 결과에서 판매문서를 클릭하면 VA03으로 넘어가면 좋겠다.
```
