# 작성본 예시 — 08-demo 경로B AI 생성 데모 (복붙용)

> `00-intake.filled.md`(데모 없음 접수)에 대한 AI 생성 데모 예시이다.
> Gate D 화면 컨펌용이며, 컨펌 후 `09-fieldmap.filled.md`로 이어진다.

```markdown
## 경로 B — AI 생성 데모

### B-§1 AI 생성 데모 (텍스트 목업)

[화면 S1 — 판매실적 조회]
┌ 조회조건 ─────────────────┐
│ 판매조직 [1000____] (필수) │
│ 생성일   [20240101] ~ [20240131] │
│ [조회] [엑셀다운로드]            │
└───────────────────────────┘
┌ 결과 ALV ─────────────────┐
│ 판매문서 | 생성일 | 고객 | 순매출 │
│ 01000001 | 20240102 | H*** | 10,500 │
└───────────────────────────┘
- 이벤트: [조회] 클릭 → ALV 표시 / 0건 → S 메시지 / 판매문서 더블클릭 → VA03(선택) / [엑셀다운로드] → 엑셀 저장

### B-§2 생성 근거
- "영업조직별 일별 판매실적" → VKORG 필수 + ERDAT 범위 조건으로 반영
- "엑셀 정리 없이 SAP에서 바로" → ALV + 엑셀 다운로드 버튼으로 반영
- "판매문서 클릭하면 VA03" → VBELN 핫스팟 드릴다운으로 반영
- [추정] 표시 항목: [엑셀다운로드 버튼 — 요구사항에 "엑셀 없이"만 있어 편의상 제안, 불필요 시 삭제]

## 공통 §3 화면 컨펌
- 화면 컨펌: [x] 컨펌(OK) [ ] 수정 요청
- 컨펌 후 다음 문서: [09-fieldmap.md 작성 → Gate F 점검]
```
