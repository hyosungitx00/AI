# 작성본 예시 — 00-intake-prompt 작성 틀 완성본 (복붙용)

```text
[신규 프로그램 요구사항 — 아래 빈칸을 채워 그대로 붙여넣으세요]

§0 접수 ★
- 세션 유형 ★: [x] 신규 프로그램 [ ] 기존 변경
- 화면 데모 ★: [ ] 있음 [x] 없음(AI 생성 요청)
- 희망 유형: [ ] 01 ALV [ ] 02 화면 [ ] 03 함수 [ ] 04 강화 [ ] 05 연동 [ ] 06 배치 [ ] 07 서식 [x] 모름(AI 판단)
- 첨부 파일: [없음]

§1 한 줄 요약 ★
- 목적(한 줄) ★: [영업조직별 일별 판매실적을 엑셀 없이 SAP에서 바로 조회]
- 사용자·빈도: [영업관리팀 5명, 매일 09시]
- 기존 대체: [없음]

§2 핵심 기능 ★
- ① [판매조직(필수)+생성일(범위) 조건으로 조회]
- ② [결과 ALV 표시(판매문서·생성일·고객·순매출)]
- ③ [판매문서 클릭 시 VA03 이동]
- ④ [엑셀 다운로드]

§3 입력(화면·조건) ★
| # | 입력 항목 | 필수 | Single/Range | 기본값·예시 |
|---|---|---|---|---|
| 1 | 판매조직 | 필수 | Single | 1000 |
| 2 | 생성일 | 선택 | Range | 당월 |
- 입력 검증: [시작일 > 종료일이면 에러]

§4 출력(조회·저장·서식) ★
- 출력 형태 ★: [x] 조회 ALV [ ] 입력 후 저장 [ ] 외부 전송·파일 [ ] 출력 서식

- 저장·전송 대상: [해당 없음]
- 서식 정보: [해당 없음]

§5 화면 데모
- 데모 없음 → [AI 생성 요청]

§6 데이터·기존 정보
- 후보 테이블·필드: [VBAK(헤더)-VBAP(아이템), KNA1 텍스트]
- 조인·조건: [VBELN 조인, 주문 유형만]
- 기존 함수·BAPI: [없음]

§7 권한·예외·제약
- 권한: [V_VBAK_VKO / SU53 TRACE 예정]
- 0건·실패 시: [0건 → "조건에 맞는 데이터가 없습니다" 표시]
- 개인정보 포함: [ ] 포함 [x] 미포함 [ ] 모름
- 금지·제약: [운영 데이터 실값 첨부 금지, 코드값만 사용]

§8 테스트값 ★
- T1 정상 ★: [VKORG=1000, ERDAT=20240101~20240131 → 100건 내외]

- T3 권한·검증: [VKORG=2000 → 에러]

§9 기타·첨부
- 보충 설명: [없음]
```
