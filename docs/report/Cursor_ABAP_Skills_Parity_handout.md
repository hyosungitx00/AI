# 논의 흐름 정리 (핸드아웃)

대화 순서대로 정리. 기승전결보다 “무엇을 묻고 → 무엇을 고쳤는지” 중심.

1. 주로 한 질문: 소스 붙여넣기, 컴파일 오류, UX, 실기 증상, 화면 가이드 → 후반 집계/비교
2. 개수(읽을 수 있는 2세션): 총 ~124–126 / 오류(중복제거) 23 / 기능수정 13–15
3. 범위: SELECT-OPTIONS 등 다른 세션은 UI엔 보이나 전사 접근 불가로 미포함
4. A에서 Skills 정착 → B Greenfield 재현 (공정 Q ≈63→16, E_compile ~18+→2)
5. ‘만족할 때까지 Q’는 주관적 → Parity(56점)로 품질, Q는 과정만
6. 최종 A=54 / B=55 동등
7. Hard Gate: 에러·미동작이면 PASS 불가 → B 첫 PASS는 Q≈12 (Q=3 아님)
8. 일반화: 동일 유형 목록화가 큰 효과, 다른 유형은 재축적 필요 (n=1)
