④ 객관성 문제

  • 기존: 만족하면 중단 + 질문 개수 → 주관적
  • DoD도 내부 체크리스트이지 외부 공인 지표 아님
  • 품질(Parity)과 과정(질문·오류 수)을 분리
  • 품질 = 동일 설계서 대비 채점표 점수
  • 과정 = 그 점수에 도달하는 데 든 Q / 오류 횟수

⑥~⑦ Q별 향상 + Hard Gate

  • A: 천천히 상승 → 첫 PASS ≈ Q57 → 최종 54
  • B: 소스 먼저 → 실기에서 막힘 → 첫 PASS ≈ Q12 → 최종 55
  • 잘못: “코드에 HTML 있음”만으로 B를 조기 PASS처럼 채점
  • Hard Gate: 활성화 실패·팝업X·ST22 버그·빈화면이면 PASS 불가
  • 미실기(코드만) → 점수 상한 40 / ‘Q=3 PASS’ 서술은 철회
