# 01 — ALV 리포트 (조회·출력)

> 선택화면 + SELECT + ALV. 가장 빈번한 유형. `00-common.md`와 세트로 제출.

## §1 데이터 원천 ★

- 주 테이블 ★: [예: VBAK — 판매문서 헤더]
- 조인 테이블·조건 ★: [예: VBAP ON VBAK-VBELN=VBAP-VBELN / 조인 없음]
- 텍스트 테이블: [예: KUNNR→KNA1-NAME1, MATNR→MAKT-MAKTX(언어=SY-LANGU)]
- 제외 조건(하드 삭제·취소 제외 등): [예: VBAK-VBTYP='C'(주문)만, 취소분 제외]
- 예상 건수·성능: [예: 일 5천건, 월 15만건 / 집계는 DB에서 SUM]

|---|---|---|---|---|---|
| ★ | 예: VBAK-VKORG | 필수 | Single+ F4 | 1000 | 판매조직 |
| | 예: VBAK-VTWEG | 선택 | Single | | 유통경로 |
| | 예: VBAK-ERDAT | 선택 | Range | 당월 | 생성일 |

- F4·체크테이블 의존성: [예: VTWEG는 VKORG 입력 후 제한]
- 선택화면 검증: [예: ERDAT From > To 이면 에러]

## §4 집계·정렬·예외 ★
