# 05 — Interface (RFC · 파일 · IDoc/Proxy)

> 외부 시스템(MES·WMS·은행·그룹사 등)과 주고받는 연동. **방향·주기·재처리**가 핵심이다. `00-common.md`와 세트로 제출.

## §1 연동 개요 ★

- 방향 ★: [ ] Inbound(외부→SAP) [ ] Outbound(SAP→외부) [ ] 양방향
- 방식 ★: [ ] RFC(동기/비동기) [ ] 파일(AL11/FTP) [ ] IDoc [ ] Proxy/SOAP [ ] OData(읽기 전용)
- 주기·용량 ★: [예: 5분 폴링, 건당 100행, 일 2만건]
- 상대 시스템·연락: [예: WMS(업체__, 담당__)]

## §2 필드 매핑 ★ (엑셀 대신 이 표 사용, 행 추가 가능)

| 순번 | 외부 필드 | SAP 필드(DDIC·BAPI) | 변환 ★ | 필수 | 예시값 |
