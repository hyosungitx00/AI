# 08 — 화면 데모 확인서 (제공 데모 분석 or AI 생성 데모)

> Gate D용 문서이다. **화면 컨펌이 완료되기 전에는 `09-fieldmap`·Gate 2 스펙·Gate 3 코드로 가지 않는다.**
> 경로 A(데모 있음)와 경로 B(데모 없음, AI 생성) 중 해당 경로 1개만 작성한다.

## 경로 A — 전달받은 데모가 있을 때 (AI가 분석, 사용자가 점검)

|---|---|---|---|
| S1 | 예: 판매실적 조회 | VKORG 입력, ERDAT 범위, [조회] 버튼, 결과 ALV | [조회] 클릭 → ALV 표시, 0건 → S 메시지 |
| S2 | | | |

- 확정으로 읽힌 점: [예: 조회조건 2개(VKORG 필수·ERDAT 선택), 결과 4열]

## 경로 B — 전달받은 데모가 없을 때 (AI가 생성, 사용자가 점검)

### B-§1 AI 생성 데모 ★ (텍스트 목업 — 표·아스키 유지, AI가 파싱할 형식)

```text
[화면 S1 — 판매실적 조회]
┌ 조회조건 ─────────────────┐
│ 판매조직 [1000____] (필수) │
│ 생성일   [20240101] ~ [20240131] │
│ [조회] [엑셀다운로드]            │
└───────────────────────────┘
┌ 결과 ALV ─────────────────┐
│ 판매문서 | 생성일 | 고객 | 순매출 │
│ 01000001 | ... | ... | ...      │
└───────────────────────────┘
- 이벤트: [조회] 클릭 → ALV 표시 / 0건 → S 메시지 / 행 더블클릭 → VA03(선택)
```

### B-§2 생성 근거 (요구사항의 어떤 문장에서 뽑았는지)

- [예: "영업조직별로 조회" → VKORG 필수 조건으로 반영]
- [예: "엑셀 없이 SAP에서 바로" → ALV + 엑셀 다운로드로 반영]
- `[추정]` 표시 항목: [예: 드릴다운 — 요구사항에 명시 없음, 편의상 제안]
