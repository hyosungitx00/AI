# 00-INTAKE-PROMPT — 붙여넣기용 요구사항 작성 틀 (참고용 보관, 접수 중단)

> 2026-09-29부터 신규 접수는 답변지 전용이다. 이 틀을 채워 붙여넣어도 접수하지 않고 답변지 I로 전환한다.
> 아래 틀은 답변지 항목 설계 참고용으로만 보관한다.

```text
[신규 프로그램 요구사항 — 아래 빈칸을 채워 그대로 붙여넣으세요]

§0 접수 ★
- 세션 유형 ★: [ ] 신규 프로그램 [ ] 기존 변경(기존명: ____, 변경점 한 줄: ____)
- 화면 데모 ★: [ ] 있음(§5에 설명) [ ] 없음(AI 생성 요청)
- 희망 유형: [ ] 01 ALV [ ] 02 화면 [ ] 03 함수 [ ] 04 강화 [ ] 05 연동 [ ] 06 배치 [ ] 07 서식 [ ] 모름(AI 판단)
- 첨부 파일: [없음 / 파일명: ____]

§1 한 줄 요약 ★
- 목적(한 줄) ★: [예: 영업조직별 일별 판매실적을 엑셀 없이 SAP에서 바로 조회]
- 사용자·빈도: [예: 영업관리팀 5명, 매일 09시 / 모르면 "모름"]
- 기존 대체: [예: 없음 / ZSD001 대체]

§2 핵심 기능 ★ (번호 목록 3~7개, 중요한 순서대로)
- ① [예: 판매조직(필수)+생성일(범위) 조건으로 조회]
- ② [예: 결과 ALV 표시(판매문서·생성일·고객·순매출)]
- ③ [예: 판매문서 클릭 시 VA03 이동]
- ④ []

§3 입력(화면·조건) ★
| # | 입력 항목 | 필수 | Single/Range | 기본값·예시 |
|---|---|---|---|---|
| 1 | 예: 판매조직 | 필수 | Single | 1000 |
| 2 | 예: 생성일 | 선택 | Range | 당월 |
- 입력 검증: [예: 시작일 > 종료일이면 에러 / 모르면 "모름"]

§4 출력(조회·저장·서식) ★ (해당 행만 남기고 나머지는 지우지 말고 비워 두세요)
- 출력 형태 ★: [ ] 조회 ALV [ ] 입력 후 저장 [ ] 외부 전송·파일 [ ] 출력 서식(PDF·라벨)
- ALV·목록 컬럼(해당 시): [예: 판매문서, 생성일, 고객, 순매출]
- 저장·전송 대상(해당 시): [예: 테이블 ____ / 상대 시스템 ____ / 모름]
- 서식 정보(해당 시): [예: A4, KO/EN, 바코드 포함 / 해당 없음]

§5 화면 데모 (있으면 작성, 없으면 한 줄만)
- 데모 있음 → 화면별 설명: [예: S1 조회조건+결과 ALV, [조회] 클릭 → ALV 표시]
- 데모 없음 → [AI 생성 요청] (AI가 §1~§4로 목업을 만들어 Gate D에서 확인받습니다)

§6 데이터·기존 정보 (알면 적고, 모르면 [모름] — AI가 SE11 확인 절차로 바꿔줍니다)
- 후보 테이블·필드: [예: VBAK(헤더)-VBAP(아이템), KNA1 텍스트 / 모름]
- 조인·조건(알면): [예: VBELN 조인, 주문 유형만 / 모름]
- 기존 함수·BAPI(알면): [예: 없음 / BAPI ____ / 모름]

§7 권한·예외·제약
- 권한(알면): [예: V_VBAK_VKO / 모르면 "모름-SU53 TRACE 예정"]
- 0건·실패 시: [예: 0건 → "데이터가 없습니다" 표시 / 모르면 "AI 제안 요청"]
- 개인정보 포함: [ ] 포함(마스킹 필요) [ ] 미포함 [ ] 모름
- 금지·제약: [예: 운영 데이터 실값 첨부 금지, 코드값만 사용]

§8 테스트값 ★ (코드값만, 실데이터 금지)
- T1 정상 ★: [예: VKORG=1000, ERDAT=20240101~20240131 → 100건 내외]
- T2 0건/예외: [예: VKORG=9999 → 메시지]
- T3 권한·검증: [예: VKORG=2000 → 에러 / 해당 없음]

§9 기타·첨부
- 보충 설명: [예: 없음 / ____]
- 첨부 위치: [예: 없음 / 파일명 ____ p.__]

[AI에게 — 위 작성 틀을 접수물로 Gate U 이해도 확인서부터 시작하십시오.
"OK" 승인 전에는 데모·필드맵·스펙·코드를 만들지 마십시오.]
```

## 섹션-게이트 대응 (사용자는 읽지 않아도 됨)

| 틀 섹션 | 사용처 | 비고 |
|---|---|---|
| §0 접수 + §5 데모 | Gate U 데모 분기 → 08-demo 경로A/B | 데모 없음이면 AI가 목업 생성 |
| §1 요약 + §2 기능 + §3 입력 + §4 출력 | Gate U 이해도 확인서 + Gate D 화면 근거 | 번호 기능이 그대로 목업·스펙으로 이어짐 |

| §7 권한·예외 + §8 테스트값 | 09-fieldmap §3~§4 + T1~T3 테스트 표 | 코드값만, 실데이터 금지 |
