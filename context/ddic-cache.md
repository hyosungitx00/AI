# DDIC 확정값 캐시 (세션 간 재사용 — 재수집 비용 절감)

> `ddic-collect`로 수집하거나 활성화로 실재가 확인된 DDIC 값만 누적하는 공용 장부다.
> 세션마다 같은 테이블을 SE11에서 다시 받아 적는 비용을 없애는 것이 목적이다.
>
> **`sessions/` 참조 금지 규칙과 충돌하지 않는다**: 새 세션이 끌어오지 않는 것은 이전 세션의
> *요구사항·설계·코드*이고, 이 파일은 시스템에서 확인된 *사실(필드 실재·타입·길이)* 만 담는다.

## 사용 규칙 (AI용 — 환각 방지의 핵심)

1. **상태 `확정`인 행만** 추가 질문 없이 `SELECT`·`TYPES`에 사용한다.
2. 상태 `미확인`인 행은 사용 금지다. `[확인필요]` 주석 + `ddic-collect` 절차로 회수한다.
3. **AI는 자기 지식으로 행을 추가하지 않는다.** 승격 근거는 둘 중 하나뿐이다.
   - 사용자가 붙여넣은 SE11/SE16N 출력 (`출처`에 `SE11-확인` 기재)
   - 해당 필드를 사용한 코드의 활성화 성공 기록 (Syntax 0건 + 실행 성공, `출처`에 세션 폴더명 기재)
4. 캐시에 없는 테이블·필드는 "모르는 것"으로 취급한다. 캐시의 침묵은 "존재하지 않음"도 "존재함"도 아니다.
5. 실재(필드가 있다)와 의미(업무상 올바른 조인이다)는 다르다. 캐시는 **실재만** 보증한다.
   조인 방향·업무 의미는 세션마다 Gate F에서 다시 확인한다.

## 캐시 현황

### MM — 구매요청 EBAN

| 필드 | Key | 타입 | 길이 | 설명 | 상태 | 출처 |
|---|---|---|---|---|---|---|
| BANFN | X | CHAR | 10 | 구매요청번호 / PR number | 확정 | 20260928-ZMM_PR_LINK_ALV01 (활성화 성공) |
| BNFPO | X | NUMC | 5 | PR 품목번호 / PR item | 확정 | 20260928-ZMM_PR_LINK_ALV01 (활성화 성공) |
| BADAT | | DATS | 8 | PR 생성일 / PR created on | 확정 | 20260928-ZMM_PR_LINK_ALV01 (활성화 성공) |
| WERKS | | CHAR | 4 | 플랜트 / Plant | 확정 | 20260928-ZMM_PR_LINK_ALV01 (활성화 성공) |
| EKGRP | | CHAR | 3 | 구매그룹 / Purchasing group | 확정 | 20260928-ZMM_PR_LINK_ALV01 (활성화 성공) |

- `SELECT-OPTIONS ... FOR eban-badat` 사용 시 `TABLES eban.` 선언 필수 (ERR-006).
- 선택조건 공란 허용 패턴은 `( a~werks = @p_werks OR @p_werks = @space )` 형태로 작성했다.

### MM·SD·FI — 연결 문서 (실재 확인 대기)

| 테이블-필드 | 용도 | 상태 | 비고 |
|---|---|---|---|
| EBKN-BANFN / BNFPO / PS_PSP_PNR / VBELN | PR 계정지정(WBS·판매오더 연결) | 미확인 | SE11 확인 필요 |
| EKPO-EBELN / EBELP / BANFN / BNFPO | 구매오더 ↔ PR 연결 | 미확인 | SE11 확인 필요 |
| MSEG-MBLNR / EBELN / EBELP | 입고 문서 | 미확인 | SE11 확인 필요 |
| RSEG-BELNR / EBELN / EBELP | 송장 문서 | 미확인 | 세션 스펙은 RBKP였고 코드는 RSEG 사용 — 재확인 필요 |
| VBAP-VBELN | 판매오더 품목 | 미확인 | SE11 확인 필요 |

### SD — 예시 전용 (업무 사용 금지)

`examples/` 와 `templates/abap/` 의 VBAK / VBAP / KNA1 값은 **문서 작성용 예시**이며 이 시스템에서
확인된 값이 아니다. 실제 세션에서는 `ddic-collect`로 다시 받아 적고 `확정`으로 승격한 뒤 사용한다.

## 승격 절차 (세션 종료 시)

1. V-1 활성화가 Syntax 0건으로 통과했으면, 그 코드가 참조한 테이블-필드는 실재가 증명된다.
2. 위 표에 `확정`으로 추가하고 `출처`에 세션 폴더명을 적는다 (타입·길이는 SE11 값이 있을 때만 기재).
3. `[확인필요]`로 남은 항목은 `미확인` 표에 남겨 다음 세션의 수집 대상으로 넘긴다.
4. 한 행은 1줄로만 적는다 (장문 금지, `practice/error-patterns.md`와 같은 규칙).
