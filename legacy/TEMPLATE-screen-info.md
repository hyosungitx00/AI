# 화면 정보 접수 양식 — `legacy/<프로그램>/screens/screen-info.md`

> 기존 프로그램의 화면을 AI가 **보지 못한 상태에서 개선**해야 하므로, 화면은 글로 확정해야 한다.
> `★` 는 필수. 비면 개선 세션에서 화면 관련 코드를 만들지 않는다 (Gate D 반려).
> 모르는 항목은 비우지 말고 `[모름]` 이라고 쓴다. AI가 확인 절차로 바꿔 준다.
> **실데이터·사용자 ID·호스트·클라이언트는 마스킹한 뒤 기입한다.**
